## Behaviour in this release

- Issue #18: an unbound sharp (base address 0) whose bits decode as FMask with unsupported
  selectors now becomes a zero sample instead of aborting translation. Bound FMask descriptors
  with unestablished B/A selectors still record the failure context and assert. CPU regression:
  `tests/test_order1886_fmask_vector.py` compiles the production replacement body for bound
  R/G/Zero/One, bound B/A (rejected) and unbound identity selectors (zero).
- Issue #54: caches are keyed by the runtime/GPU-library build; a new build starts a fresh cache
  while older ones stay for rollback. A cached pipeline that fails during warm-up is skipped,
  rebuilt on demand and rewritten in place. Verified headless with the real 37-pipeline cache
  (control 37/37; forced rejection: 24 graphics skipped, 13 compute replayed, presenter ready).
